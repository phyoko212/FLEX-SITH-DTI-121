# FlexSith FlexBottle Demo

A presentation-ready responsive website + PWA demo based on the team's handwritten concept.

## Included
- Product landing page
- FlexBottle 500ml — ฿799
- FlexBottle + Power Bank — ฿1,299
- Accessory modules — ฿199–399 concept range
- Interactive Collapse → Twist → Swap demo
- Shopping cart and fake checkout
- Business economics / BEP dashboard
- Target market section
- PWA manifest + service worker

## Run
1. Put all files in one folder.
2. Open `index.html` in a browser.
3. For PWA installation/service-worker testing, use a local server or GitHub Pages.

## GitHub Pages
Upload the files to a GitHub repository and enable Pages from Settings → Pages → Deploy from branch → main/root.

## Important
This is a front-end demonstration. Checkout is simulated and does not process real payments or orders.
